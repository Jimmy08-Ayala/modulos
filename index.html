Acuerdos de trabajo en GitHub

  • Commits con formato tipo: descripción (ej. feat: agregar ficha módulo 3.1).
  • Antes de subir: git pull para evitar conflictos.
  • Nunca se suben contraseñas, claves, tokens ni datos personales.
  • El repositorio es público: todo lo que suban lo puede ver cualquiera.

Comandos para subir tu proyecto a GitHub

# 1. Inicializar el repositorio git init # 2. Agregar todos los archivos git add . # 3. Hacer el primer commit git commit -m "feat: primer commit del HUB 3DS-B" # 4. Cambiar el nombre de la rama a main git branch -M main # 5. Conectar con tu repositorio remoto (reemplaza la URL) git remote add origin https://github.com/tu-usuario/tu-repositorio.git # 6. Subir los cambios git push -u origin main
